# Bom Paladar · Catering Website

Website for Bom Paladar, a catering business in Luanda, Angola.

[![Live](https://img.shields.io/badge/Live-pmcbompaladar.com-111111?style=for-the-badge)](https://www.pmcbompaladar.com) ![Status](https://img.shields.io/badge/Production-2ea44f?style=for-the-badge)

<img src="screenshots/hero.png" alt="Bom Paladar · Catering Website on desktop and mobile" width="100%">

</div>

## Highlights

- **Catalog ordering** by the dozen.
- **Buffet budget calculator:** enter the number of guests, get a price range, send it on WhatsApp in one tap.
- **Events showcase** for buffets and coffee breaks.
- **Mobile first** and responsive.
